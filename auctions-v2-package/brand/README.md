# Auctions / Remates gavel identity

The user supplied a replacement SVG and requested that it replace the previous gavel. The active logo now uses the six paths from the black, right-hand gavel in that SVG. Geometry is retained exactly; only scale, position and monochrome fill are adapted for the existing application surfaces. The split background and duplicate left-hand mark are excluded from UI assets. The original supplied SVG is preserved byte-for-byte as source-gavel.svg.

Confirmed direction: use the replacement supplied SVG. Existing Auctions typography and the deep green app palette remain proposed design choices. Assets retain editable XML paths; wordmarks retain editable system-font text. Final production wordmark typography can be outlined after the font is approved.

The app uses the light mark in the desktop rail and the dark mark in the home link on mobile and the sign-in concept. The brand/home link returns to the default Properties listing. Documentation headers and the package index use the light mark. No version suffix or badge is part of the displayed app identity.
