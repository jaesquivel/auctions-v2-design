# Auctions / Remates

The current [React / Next.js preview](frontend/README.md) uses the official shadcn Radix Nova components and fictional auction records. Start it from frontend/ with npm ci and npm run dev, then open http://127.0.0.1:3000/es/properties.

The [documentation and design index](auctions-v2-package/index.html) links requirements, data/API specifications, design decisions, screenshots and the older offline HTML reference. Production services are not implemented; see the frontend README for simulation boundaries. No ZIP is required.
