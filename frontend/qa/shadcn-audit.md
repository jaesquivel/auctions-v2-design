# shadcn deviation audit

Reviewed 13 November 2026. Scope: current frontend only. No application code was changed. This is a static source comparison, not an accessibility audit or a fresh browser/build validation.

Compared all 36 installed registry UI modules plus the mobile hook against the current official Radix Nova/Base Nova registry (37 files). The two DataTable files are local compositions and were reviewed separately. Reviewed 72 application/source/test/config files, configuration, theme CSS and dependency declarations. Old mockups are excluded by the frontend-only instruction.

“Out of the box” here means the selected Neutral/Geist Nova preset, not every shadcn demo copied verbatim. Shadcn supplies primitives and compositional examples; application screens necessarily add layout and behavior. Stock variant choices, normal links, labels/translations and domain fields are not primitive source forks.

## Result

The core primitives are stock-derived: 27 registry files match after aliases, Lucide icon substitution and repository formatting. The other 10 differ only in import blank lines or CLI-resolved heading-font, menu, direction and icon attributes. Those differences are not evidence of handmade redesigns. Current registry URLs are mutable; this comparison does not reconstruct a historical release. Existing qa/components.json hashes alone were not treated as independent evidence.

The Base Sidebar files were copied with aliases/icons resolved, but two generator markers remain unprocessed: cn-rtl-flip and cn-font-heading. These are listed below rather than described as fully generated output. All substantive app adaptations and consistency gaps follow.
